## 判定

先确认材料包含前序对象选择、商品带入、分批数量、进度回写、状态条件、订金/付款/欠款处理。核对表留在验收侧，不喂给模型。

合格成稿必须讲清对象如何交接、允许哪些不同路径、实际具体规则以及最终系统结果；业务读者能连续复述怎样办理。保存成功、引用存在、阶段数量均不是质量通过。

任务致命业务错误包括：编造强制前序单据或审批、遗漏关键对象交接、把独立维护操作伪装成必经步骤、混用不同业务类型规则、金额或状态解释明显错误、重要规则仅写“条件满足”。原始草稿和审阅稿分别核对，任何重要错误不能靠人工重写隐藏。

结果分为：本案例能力通过；生成通过但审阅退化；材料充分但本次模型任务未通过；材料或工具问题导致未能有效测量。一次失败不能证明所有模型均无能力，但足以停止按当前方式扩大全仓投入。

本次没有第二候选自动改进或第三调用。后续是否修改自动选材、换模型或恢复复杂输出，必须依据本实验结果讨论。预计阅读包准备与核验为几十分钟，模型耗时采用真实记录，不承诺固定结束时刻。
