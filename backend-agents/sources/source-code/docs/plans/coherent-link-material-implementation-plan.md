## 验收范围与门禁

- 采购优先：两处来源编号联系。跨任务时须 O2 明确订单对象对应；不得按名称拼接。实际三对象、两联系及来源齐全才能说请购、订单、入库连上。
- 调拨为对照；财务及期间统计验证骨架对象如何细化。
- 恢复旧失败稿中的真实技术锚点是定向恢复，不冒称自主全仓发现。
- 不给 Prompt 参考图答案，不搬入 PoC 包作正式成功，不由宿主 Agent 手工添原文。
- 当前容量配置不增加，不换模型；记录同选材压缩和完整 EXTRACT/REVIEW 成本，不宣称任意4k/8k兼容。
- 原文完整提交仍误读时，材料与模型质量分别报告；机械缺陷持续修复，不能靠无限模型修稿收口。
