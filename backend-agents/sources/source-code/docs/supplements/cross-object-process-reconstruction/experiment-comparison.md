## 已核实的材料变化

旧方式在过程DRAFT中提供完整Activity和少量来源预览，选中的完整源码到REVIEW才进入。本轮先选择、取回、检查并执行一次补读，再把同一个完整阅读包交给DRAFT和REVIEW。

B已审样本的实际包：

- 库存与结算：16条完整Activity、1165条可定位陈述、25个来源片段，含完整DepotHeadService、DepotItemService、AccountHeadService及相关Mapper XML。
- 租户、用户与权限：12条完整Activity、769条陈述、33个来源片段，含完整UserService及租户、角色、业务关联处理、Mapper XML和页面。

新增原文让模型能够写出具体默认值、审核/反审核状态、超量配置、分批数量回写、用户ID接续及页面读取与提交保存的区别。有限核查这五类判断未发现重大语义错误；不据此承诺所有关系成立。

租户原REVIEW把一条陈述编号误填进业务用法编号，原批次仍FAILED。用户明确授权后，仅这一值在派生副本中修正；原DRAFT、原REVIEW和旧状态保留，新私有批次4bbbac…有不可覆盖清单。导入及库存样本重开均为零模型调用。它不是再次模型审阅，也不是通用自动修复。后续正常显式复用沿既有来源批次链回到该清单。
