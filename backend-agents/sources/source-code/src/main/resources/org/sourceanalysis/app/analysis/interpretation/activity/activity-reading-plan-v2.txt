你正在为入口选择完整的局部业务阅读材料，本阶段不生成业务解释。

输入给出入口正文、completeUnits 和分页导航；仅 completeUnits 算已读。程序顺序展示页面；requestedNavigationPages 可用 "2" 或 "page-2"，requestedUnitKeys 只能引用目录短键。currentPage=0 是导航结束后的选材请求。已读正文表明还需已有方法或 SQL 时，必须从 availableUnits 选键，不能只写 unknowns；catalogStatus=CAPACITY_EXCEEDED 时保留缺口，不猜键或目录外源码。

scopeState.definedSlices 是此前定义，finalSliceKeys 是此前认可范围。currentOpenScopeIssues 只列当前 final 范围的问题；historicalDiagnostics 保留旧轮证据，已明确替代的旧问题不能继续驱动选材。每次返回本轮完整 finalSliceKeys，可引用已有定义或本轮 slices。移除此前 final key 时，supersededSlices 必须提供唯一 disposition：replacementSliceKeys 只能引用已定义且属于本轮 final 的 key；无法替代可为空，但 reason 要明确缺口。不要按名称猜替代、重复 disposition 或形成环。相同 key 可跨轮修订，同轮不可重复定义。

finishReading=true 表示冻结本轮范围，不证明材料充分。必需单元缺失、容量超限或导航未展示仍会登记不足，且程序不会为修复结束声明另加一轮；仍需选材时返回 false。

已读代码能独立说明局部行为时就输出 scope；局部依赖缺失写 unknowns，不能让已知动作归零。每个 scope 说明问题、触发和结果；过滤、分页、汇总若组成一个动作，应优先修订原 key。程序不按中文相似度合并。

slices[].entryKeys 只能取顶层 entryKeys（如 E1）；M 方法键、X SQL 键只进入 requiredUnitKeys 或 sharedContextUnitKeys。sliceCapacity.maxPacketBytes 是单个 DRAFT 包上限。收到 INPUT_CAPACITY_EXCEEDED 后收窄同 key 或拆分；换 key 必须明确替代旧 key，不能重交相同超限集合，也不能为字节数删除必要条件；确实装不下则保留缺口。
