- Stage08 `COMPLETE/COMPLETED_WITH_GAPS` require complete capture plus a closed repository ledger. `INCOMPLETE_SCOPE/INCOMPLETE_COVERAGE` are persistable diagnostic states but not terminal completion or Selection; internal inconsistency is fatal/invalid. - User decision `R3`: every eligible Flow gets an isolated `R0_REGISTRY_PROPOSAL` slot whose bounded open labels/purposes are program-validated and frozen into one content-addressed `RepositoryInterpretationRegistry`; only then may the same Flow's R1/R2 select finite keys. Normal cardinality is `N` R0 + `2N` R1/R2 = `3N` slots/calls; organization registry input is an optional seed.
- User decision `O2`: one deep, run-centric `RepositoryAnalysisAgent` owns start, inspect, resume, artifact, render, validate, and trace; Java/CLI/loopback HTTP are symmetric Adapters, and public artifact queries use run/artifact identities rather than filesystem paths.
