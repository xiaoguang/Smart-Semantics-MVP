# Task 4：全站可读性与响应式实施报告

## 完成范围

本任务只调整当前 `AppLayout` 可达的应用壳、指标、业务规则、同义词、时间语义、本体及登录界面。未改动 Task 1–3 的证据、标准文档、物化或协作事实合同。

### 应用壳

- 600px 以下增加固定五项底栏：数据标准化、AI 建模、本体、指标、更多。更多菜单仅收纳业务规则、同义词和时间语义，七个业务页在手机上全部可达。
- Header 的项目／版本与视图／用户操作分成两层。320px 下两个上下文选择器仍保留可读宽度，不再逐字折叠。
- 底栏预留 `safe-area-inset-bottom`。Drawer／Modal／Dropdown 的层级分离；全屏抽屉开启时隐藏底栏，关闭后恢复。

### 数据列表深模块

- 新增 `ResponsiveDataView` 和 `ResponsiveDataCard`。页面只定义业务列、卡片字段与操作；模块统一负责桌面表格、`scroll.x`、手机卡片、空态、分页和数据集变更后回到第一页。
- 指标、业务规则、目标值、同义词／未识别词、时间规则、日历和节假日已迁移。桌面端声明明确列宽，手机端保留同等状态与操作。
- 390px 及以下卡片字段自动单列，长名称正常换行，操作区可换行。同义词桌面与手机均默认 20 条分页。

### 抽屉与本体

- 720px 以下的可达抽屉统一为全屏宽度、单列表单、无内部横溢。编辑抽屉使用 sticky footer 并预留安全区；字段、关系、层级和值定义从 Header `extra` 迁到底部操作。
- 登录体验账号的动作区可换行，390px 下复制／使用按钮不裁切。
- 本体主列表、关系列表和值定义都保留“列表 → 详情 → 返回”。关系手机改为信息卡；层级和值定义保留独立入口。本体详情的六个 Tabs 在窄屏采用紧凑、可滚动导航，避免一次点击只滚动不切换。
- 来源中心的连接 ID、批次 ID、fingerprint 和 Manifest Locator 继续统一使用 `ReadableTechnicalValue`：长值可展开／收起、可复制，中文名称不使用 `break-all`。
